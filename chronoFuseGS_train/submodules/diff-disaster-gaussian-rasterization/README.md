# Differential Gaussian Rasterization

This is the rasterization engine used for the ChronoFuseGS paper. It is adapted from the original implementation by Kerbl et al. ("3D Gaussian Splatting for Real-Time Radiance Field Rendering") with minor modifications to support the ChronoFuseGS pipeline.

[Original implementation](https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/)
